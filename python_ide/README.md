# Лекция "Работа с Python в среде разработки"

[Презентация по ссылке](https://docs.google.com/presentation/d/1O2v-hMEdc-qXt0mZ3P-ZQUexFsqHle_pTc-d83b-A8s/edit?usp=sharing)

## Ключевые моменты

* Задача инструментов разработки: помочь программисту эффективно писать код.
* Инструменты можно разделить на следующие категории:
  * `Программное обеспечение`: компиляторы, отладчики, движки и др.;
  * `Редакторы`: редакторы текста или кода;
  * `Инструменты поддержки цикла разработки`: системы контроля версий, контейнеризация, среды тестирования и др.;
  * `Среды разработки`: совокупный программный продукт, включающий вышеперечисленное программное обеспечение для разработки.
* Инструменты для разработки на Python:
  * Терминал
  * Idle
  * Текстовый редактор (NotePad, TextEdit, KWrite)
  * VS Code
  * PyCharm
  * JupyterHub
* `Модуль` — файл с расширением .py, который содержит команды на языке Python
* Изолированные среды необходимы для управления зависимости для разных проектах на Python
* Последовательность исполнения операций интерпретатором Python:
  * Скрипт в файле .py
  * Байт-код в файле .pyc _(для CPython)_
  * Исполнение на PVM _(Python Virtual Machine)_
* `Отладка кода` — процесс поиска ошибок с помощью специальных программных инструментов
* `VCS` — система, позволяющая контролировать, организовывать и отслеживать различные версии в истории компьютерных файлов в виде исходных кодов. Одной из популярных систем контроля версий является `Git`.

### Для компьютеров Windows в Академии

_Инструкция отображает общую последовательность действий. В рамках задания этапы могут меняться._

1. Проверить наличие Python

   * Открыть в меню Пуск `PowerShell`
   * Проверить наличие интерпретатора Python

      ```
      python -v
      ```

   * В ответ вы получите _Python_

2. Проверить наличие системы контроля версий `git`

   * В `PowerShell` введите команду

      ```
      git -v
      ```

   * Если git не установлен:

     * [скачайте установщик git по указанной ссылке](https://github.com/git-for-windows/git/releases/download/v2.47.0.windows.1/Git-2.47.0-64-bit.exe)
     * откройте установщик
     * на каждом вопросе нажмите _Next_

   * Перезапустите PowerShell и повторите команду выше.

3. Создание репозитория проекта на `GitHub`

   * Зайдите в аккаунт GitHub _(предварительно зарегистрируйтесь)_.
   * Создайте `публичный` репозиторий для выполнения нового задания _(если указано в задании, то необходимо создать форк уже существующего репозитория)_

     * В репозитории при создании должен быть добавлен файл `README.md`

   * Добавьте участников команды, если необходимо _(на странице репозитория вкладка Settings > Colloborators. Приглашение можно принять в Github или на эл. почте)_

4. Генерация и добавление `ssh-ключей` на GitHub

   * Открыть в меню Пуск `PowerShell`
   * Сгенерируйте ssh-ключи, если их нет в папке _.ssh_

      ```
      ssh-keygen
      ```

   * Вывод консоли на команду ssh-keygen. _При введении `passphrase` символы не отображаются в целях безопасности!_
    
      ```
      Generating public/private rsa key pair.
      Enter file in which to save the key (/path/.ssh/id_rsa): 
      --> нажмите Return
      Enter passphrase (empty for no passphrase): --> введите n12345 (пример)
      ```

   * Перейдите в каталог вашего пользователя `С:\Users\<ваш пользователь>\` и перейдите в папку `.ssh`. Перед вами будет два файла один из которых будет с расширением `*.pub`
   * Полностью скопируйте содержимое, выделив текст с помощью `Ctrl+A`
   * Передайте ключ на `GitHub`. Для этого:

     * Откройте `GitHub`
     * Войдите в аккаунт
     * Перейдите в настройки _(Settings)_
     * Откройте пункт _SSH and GPG keys_.
     * Передайте скопированный открытый ключ из PowerShell сервису GitHub

5. Настройка проекта в VS Code

   * Откройте `VS Code`. Первичную настройку пропустите _(Mark done)_.
   * Откройте терминал в VS Code _Terminal > New Terminal_
   * Введите команду для перехода в папки с проектами `envs`
  
      ```
      cd envs
      ```

     * Если папки `envs` нет, то перейдите в Проводник
     * Перейдите в каталог вашего пользователя `С:\Users\<ваш пользователь>\`
     * Создайте папку `envs`
   * Введите команду для стягивания репозитория. Ссылку на github-репозиторий можно найти на его странице в разделе _Code > SSH > git@github.com:user/repo.git_

      ```
      git clone <ssh-ссылка на репозиторий>
      ```

   * Для открытия папки проекта, откройте вкладку _File > Open Folder_ и выберите каталог стянутого проекта.

6. Настройка изолированной среды

   * Создайте новый файл `main.py`
   * Установите предложенное расширение Python
   * Для проверки работоспособности после завершения установки расширения запустите код через клавишу _Запуск_ сверху справа.
   * Настройте среду нового проекта. Откройте терминал во вкладке _Terminal > New terminal_
   * В открывшемся терминале введите команду для установки инструмента настройки среды

      ```
      pip install virtualenv
      ```

   * Затем, создайте изолированную среду

      ```
      virtualenv .venv
      ```

   * Справа в проводнике VS Code появится новая папка `.venv`
   * Трей _(нижняя полоса VS Code с параметрами страницы)_ показывает текущий запущенный интерпретатор справа _(например. 3.9.6)_. Нажмите на него и выберите в контекстном окне выше `Python3.x.x (.venv)`
   * Запустите файл main.py в выбранной ранее среде _.venv_
   * Также можно запустить среду в терминале через ```.venv/Scripts/activate```

7. Продолжайте работу с проектом, установив зависимости и описав новые модули внутри проекта. Для работы с `git` репозиторием используйте [список следующих команд](/git_basic/README.md#основные-команды)

## Термины

Термин | Определение
:-- | :--
Интерпретируемый язык | язык программирования, исходной код на котором выполняется интерпретатором — программой, переводящей исходный код в промежуточное состояние для построчного исполнения интерпретатором.
Отладчик | Компьютерная программа для автоматизации процесса отладки: поиска ошибок в коде
Модуль | Файл с расширением .py, который содержит команды на языке Python
Системная консоль (терминал) | Интерактивная система ввода-вывода, обеспечивающая взаимодействие человека-оператора с компьютером
Ввод-вывод | Взаимодействие между обработчиком информации (например, компьютер) и внешним миром, который может представлять как человек-оператор, так и другая система обработки информации. Ввод — сигнал или данные, полученные системой, а вывод — сигнал или данные, посланные ею.
